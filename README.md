# 株価データ自動取得・可視化ツール

## 1. 概要

Pythonを使用して株価データを取得し、Excelへの出力および株価チャートの自動生成を行う個人制作物です。

複数銘柄の株価を一定間隔で取得し、取得したデータを銘柄ごとにExcelへ保存するとともに、株価の推移をグラフとして確認できるようにしています。

## 2. 開発背景・目的

実務でAnsibleを使用した自動化に取り組んだ経験から、手作業による作業を自動化することで、作業時間の短縮やヒューマンエラーの削減につなげられることに興味を持ちました。

そこで、実務で得た自動化の考え方を、業務以外の自分が興味を持っている分野にも応用できないかと考えました。

個人的に株価に興味があり、複数の銘柄の株価を確認する場合、手作業で確認すると時間がかかり、確認漏れが発生する可能性があります。

そこで、株価データの取得からExcelへの出力、チャートの作成までを自動化することで、手作業による確認を減らし、効率的に情報を確認できる仕組みを作成しました。

本ツールは、実務で得た「作業を自動化し、ヒューマンエラーを減らす」という考え方を、個人的な興味のある分野へ転用した学習成果物です。

## 3. 使用技術

- Python
- yfinance
- pandas
- matplotlib
- openpyxl
- Git / GitHub（公開時に使用予定）

## 4. 主な機能

- 複数銘柄の株価データ取得
- 15分間隔での株価データ取得
- 銘柄ごとのExcelシートへのデータ出力
- 株価推移のチャート自動生成
- 最高値・最安値の自動判定
- 各時点の株価表示
- 実行日ごとのフォルダ自動作成
- タイムスタンプ付きファイル名による保存

## 5. 工夫した点

最初は1銘柄の株価データを取得するところから始めました。

1銘柄での取得ができた段階で、「複数の銘柄を一度に取得した場合はどうなるのか」「複数の銘柄を効率よく管理するにはどうすればよいか」と考え、複数銘柄をまとめて処理できるようにしました。

また、単に現在の株価を取得するだけではなく、「時間の経過によって株価がどのように推移するのか」が気になったため、15分間隔でデータを取得し、時間ごとの株価をExcelに出力するようにしました。

さらに、取得したデータを確認しやすくするため、株価の推移をグラフ化し、最高値・最安値を自動的に判定して表示するようにしました。

データの保存についても、実行した日付ごとにフォルダを作成し、その中に時刻付きのExcelファイルとチャート画像を保存するようにしています。

## 6. 苦労した点

1銘柄の株価を取得するところまでは比較的スムーズに進めることができましたが、複数銘柄を扱う段階で、どのような方法でデータを取得・処理すればよいかを考えることに苦労しました。

特に、銘柄ごとに同じ処理を繰り返す必要があるため、銘柄を個別に記述するのではなく、銘柄コードと名称をまとめて管理し、それを順番に処理する方法を考えました。

また、時間を扱う部分についても苦労しました。取得した株価データの日時を扱いやすくするための調整や、取得した時間をグラフ上に正しく表示することなど、時間に関する処理を調整しました。

## 7. 実装を通して学んだこと

今回の制作を通して、単にコードを動かすだけではなく、「一つできたものを、複数の対象に拡張するにはどうすればよいか」「取得したデータをどのように整理すれば後から確認しやすいか」と考えることの重要性を学びました。

また、実務で経験したAnsibleによる自動化の考え方を、Pythonを使った個人制作にも応用することで、自動化によって作業時間を短縮し、確認漏れやヒューマンエラーを減らすという考え方を、別の分野でも実践しました。

## 8. AIの活用について

本ツールは個人学習の一環として作成しました。

実装にあたっては生成AI（ChatGPT）を活用し、コードの作成・改善や実装方法について相談しながら開発しています。

自身の環境で実行・動作確認を行い、必要に応じて修正・調整しています。

そのため、本作品は「すべてのコードをAIを使わずにゼロから一人で記述したもの」ではなく、自分で課題や目的を考え、生成AIを活用しながら実装・検証した成果物です。
